Containerized web infrastructure

A practical roadmap for building, validating, and extending a Docker-based WordPress platform.

PROJECT BRIEF

One virtual machine. Multiple isolated services. One controlled public entrypoint.

The Debian virtual machine runs Docker Compose. Docker creates isolated service containers and connects them through a private bridge network. Only the public NGINX gateway accepts browser HTTPS traffic.
